## 🔍 Finding Translation Keys

All 200+ keys are organized in `constants/translations.ts`:

**By Feature:**
- Navigation (home, services, explore, bookings, profile, etc.)
- Authentication (login, signup, register, etc.)
- Common UI (loading, error, success, retry, etc.)
- Home & Services
- Profile & Bookings
- Admin Pages
- Business Pages
- Organization Pages
- Stack Pages (about, help, privacy, terms, safety, etc.)

**How to Find:**
1. Open `constants/translations.ts`
2. Find the English (en) translation
3. Copy all keys
4. Translate each value
5. Done!

Or use the template in `QUICK_START_LANGUAGES.md`
