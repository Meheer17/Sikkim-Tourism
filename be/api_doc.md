# API Reference — concise

Global notes
- Auth: All APIs require `Authorization: Bearer <JWT>` except `/auth/*`.
- MongoDB: every document has an autogenerated `_id` (ObjectId string).
- Reference IDs: All reference fields (l_id, type_id, uid, cid, b_id, bid, message_id) are stored as MongoDB ObjectId types in the database.
- Timestamps: `created_at` and `updated_at` are server-managed (do not send on create/update).
- CRUD mapping: list = GET /resource, create = POST /resource, read = GET /resource/{id}, update = PUT /resource/{id}, delete = DELETE /resource/{id}.
- Pagination: `skip` (>=0), `limit` (>0).
- Upload processing placeholder: processUpload(file)

Validation & reference rules (concise)
- Reference fields must be valid MongoDB ObjectId strings (e.g., `l_id`, `type_id`, `uid`, `cid`, `b_id`, `message_id`, `bid`).
- Email: valid email format, unique.
- Password: min length 8 (store hashed).
- String lengths: names and short_description max 255 chars.
- Numbers: `price >= 0`; `size > 0`; `skip >= 0`; `limit > 0`.
- Date/time formats:
  - `scheduled_at`, other datetimes: ISO 8601.
  - `open_hours.start` / `open_hours.end`: "HH:MM" 24-hour.
- Enums must match allowed values.
- Server-managed fields provided by client are ignored.

Endpoints (endpoint — short overview — params)

- Endpoint: POST /auth/signup
  - Short overview: Create user; returns JWT (7 days)
  - Params:
    - name — body — string — required — user full name (max 255)
    - address — body — string — required — postal/address
    - gender — body — string — optional — gender
    - email — body — string — required — valid email
    - password — body — string — required — min 8 chars

- Endpoint: POST /auth/signin
  - Short overview: Sign in; returns JWT (7 days)
  - Params:
    - email — body — string — required — valid email
    - password — body — string — required — plain password

- Endpoint: POST /auth/forgetpassword
  - Short overview: Request password/reset token (token expires 15 minutes)
  - Params:
    - email — body — string — required — valid email

- Endpoint: POST /upload/{type}
  - Short overview: Upload file ('glb' | 'image' | 'audio' | 'video'); creates FILES record (uses processUpload(file))
  - Params:
    - type — path — enum('glb','image','audio','video') — required — upload category
    - file — body (multipart/form-data) — file — required — binary file (field name: file)
    - name — body/form — string — required — original filename (max 512)
    - message_id — body/form — string — required — references MESSAGE._id
    - size — body/form — integer — required — bytes (>0)
    - metadata — body/form — object — required — arbitrary metadata

- Endpoint: GET /business
  - Short overview: List businesses (supports pagination, filter by position and/or type)
  - Params:
    - skip — query — integer — optional — pagination offset
    - limit — query — integer — optional — pagination size
    - position_lat — query — number — optional — latitude for nearby filter
    - position_lng — query — number — optional — longitude for nearby filter
    - radius_m — query — integer — optional — radius in meters
    - type_id — query — string — optional — business_TYPE._id filter

- Endpoint: POST /business
  - Short overview: Create a business or event (business model)
  - Params:
    - name — body — string — required — business.name (max 255)
    - description — body — string — required
    - short_description — body — string — required
    - open_hours — body — object {start: "HH:MM", end: "HH:MM"} — required — start < end
    - type_id — body — string — required — references business_TYPE._id
    - l_id — body — string — required — references LOCATION._id
    - scheduled_at — body — string (ISO 8601) — required — scheduled datetime

- Endpoint: GET /business/{b_id}

Collections (fields & concise validations)

- USER
  - _id (ObjectId auto)
  - name — string — required — max 255
  - address — string — required
  - gender — string — optional
  - last_synced_at — object {x: string, y: string} — optional
  - role — enum('user','organiser','business','admin') — optional
  - email — string — required — unique, valid email
  - password — string — required — min 8 (hashed)
  - secret — object {token: string, expiry: date} — optional
  - approved — boolean — optional (default false)
  - created_at/updated_at — server-managed

- LOCATION
  - _id, name, description, short_description, position {x:number,y:number}, metadata {object}, type enum(...), created_at, updated_at
  - All fields required except timestamps

- business
  - _id
  - name — string — required
  - description — string — required
  - short_description — string — required
  - open_hours — object {start:"HH:MM", end:"HH:MM"} — required
  - type_id — string — required — references business_TYPE._id
  - l_id — string — required — references LOCATION._id
  - scheduled_at — string (ISO 8601) — required
  - created_at/updated_at — server-managed

- FILES
  - _id
  - name — string — required
  - message_id — string — required — references MESSAGE._id
  - size — integer — required (>0)
  - metadata — object — required
  - created_at — server-managed

- MESSAGE
  - _id
  - uid — string — required — references USER._id
  - cid — string — required — references COMMUNITY._id
  - text — string — required
  - created_at — server-managed

- COMMUNITY
  - _id
  - name — string — required
  - decription — string — required
  - created_at/updated_at — server-managed

- USER_business
  - uid — string — required — references USER._id
  - bid — string — required — references business._id
  - role — enum('owner','user') — required
  - created_at/updated_at — server-managed

- USER_COMMUNITIES
  - uid — string — required — references USER._id
  - cid — string — required — references COMMUNITY._id
  - role — enum('owner','member') — required

- business_TYPE
  - type — enum('tourist_entry','hotel','restaurant','cab','guide','event') — required
  - category — enum('event','book','buy') — required

- SERVICES
  - _id
  - name — string — required
  - price — number — required — >= 0
  - bid — string — required — references business._id
  - description — string — optional
  - features — array — optional
  - short_description — string — optional
  - metadata — object — optional (tourist_entry: add externalid; cab: add vehicle type)

References & formats summary
- ObjectId fields: `^[0-9a-fA-F]{24}$`
- Email: standard email regex
- ISO datetimes for datetime fields
- HH:MM (24h) for open_hours
